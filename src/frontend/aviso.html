Términos y privacidad de la demostración

Esta versión forma parte de un proyecto académico. Utiliza exclusivamente datos ficticios y una contraseña de prueba que no uses en otros servicios.

Qué aceptas al registrarte

Crearás una cuenta de prueba con rol Cliente. El registro permite comprobar el funcionamiento del proyecto; no genera un pedido, una compra ni un compromiso de entrega.

Información que guarda esta versión

Se guardan el nombre y el correo de prueba, una representación protegida de la contraseña, el rol y estado de la cuenta, y tu aceptación de este aviso con su fecha. La contraseña original no se almacena. La confirmación de contraseña solo se utiliza en el formulario.

Para qué se utiliza y quién puede verla

Los datos se utilizan para probar el registro, detectar correos duplicados y verificar las condiciones de aceptación del proyecto. Los integrantes del equipo con acceso al entorno de desarrollo pueden revisar los registros de prueba y los diagnósticos técnicos. No se incluye publicidad ni analítica de terceros en esta pantalla.

Protección del formulario y conservación

El navegador utiliza una cookie técnica para proteger el envío del formulario. Los registros de prueba permanecen en el entorno de desarrollo hasta que el equipo los retire o reinicie la demostración; no utilices esta versión como archivo de información personal.

Antes de usar el sistema con datos reales

El negocio deberá revisar y aprobar su aviso definitivo, las finalidades, los accesos, el plazo de conservación y el canal para atender solicitudes de las personas. Este aviso describe únicamente la demostración académica actual.
