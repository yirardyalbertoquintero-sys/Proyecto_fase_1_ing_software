# Guías académicas del docente

Copias intactas de los PDF proporcionados por el equipo:

- [Plan de ejecución de Ingeniería de Software I](Plan_de_ejecucion_Ingenieria_de_Software_I.pdf).
- [Explicación ampliada de las fases](Fases_del_proyecto_explicacion_ampliada.pdf).

Los archivos originales de Descargas se conservan. Estas guías establecen entregables académicos, no reglas nuevas del negocio. Sus calendarios difieren; la fecha efectiva de entrega o defensa continúa pendiente de confirmación.

El plan de ejecución exige al menos 80 % de los casos principales; el equipo mantiene la meta de los seis principales y las funciones de apoyo del alcance mínimo. La integración en el informe final debe citar la guía correspondiente sin reescribir el DOCX de requisitos aceptado.
