# Archivo histórico: conservar, no usar como requisitos

Esta carpeta reúne los documentos que antes ocupaban la raíz y las extracciones antiguas de la carpeta original. Se han trasladado sin cambiar el contenido de los archivos. No son la fuente de verdad del proyecto.

- `documentacion-anterior/`: Word que ya estaban registrados en Git, conservando sus nombres y la estructura anterior de fase 1.
- `local-original/`: archivos locales que todavía no estaban registrados en la carpeta original, incluidos el AGENTS anterior, planes, extracciones Markdown e imágenes. Se conserva su estructura relativa para mantener su contexto.
- `repositorio-anidado/REFERENCIA.md`: registra la referencia Git histórica `7451ee4bb3d5ed98daa2a32ec54213e242c65c38` que antes estaba en la raíz. Era un enlace Git sin contenido inicializado y sin `.gitmodules`; se conserva su identificador y procedencia como documentación y en el historial, retirando el enlace incompleto de la estructura activa.
- `INVENTARIO.csv`: nombres, tamaños y SHA-256 de los 23 archivos trasladados. El inventario no incluye este README ni el nuevo registro explicativo de la referencia Git.

Los archivos llamados AGENTS dentro del archivo histórico son evidencia de instrucciones anteriores; no deben aplicarse al desarrollo actual. El AGENTS de la raíz y el DOCX vigente determinan el trabajo autorizado.
